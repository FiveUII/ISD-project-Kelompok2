## Phase Goal

**As a** librarian, **I want to** check out copies to students and process returns, **so that** the library can track who has which book and automatically surface overdue loans without manual intervention.

  <action>
    Create backend/app/routers/loans.py with two routers:

    **loans_router** (prefix="/librarian/loans", dependencies=[Depends(require_librarian)]):

    POST /api/librarian/loans/checkout (body: CheckoutRequest → LoanResponse, status 201):
    - Load Copy by copy_id; if not found → 404
    - Check copy.status == CopyStatus.available; if not → 409 "Copy is not available for checkout" (per D-05)
    - Load User by user_id; if not found → 404
    - Check user.role == UserRole.student; if not → 400 "Can only check out to student accounts" (per D-05)
    - Load LibrarySettings row (id=1); get loan_period_days (per D-04)
    - Calculate due_date = datetime.now(timezone.utc) + timedelta(days=loan_period_days)
    - Create Loan(copy_id=copy_id, user_id=user_id, due_date=due_date)
    - Set copy.status = CopyStatus.on_loan
    - session.add(loan); await session.commit(); await session.refresh(loan)
    - Eager-load copy → book and borrower for the response (use selectinload or joinedload)
    - Return LoanResponse.model_validate(loan)

    PATCH /api/librarian/loans/{loan_id}/return (→ LoanResponse):
    - Load Loan by loan_id; if not found → 404
    - If loan.returned_at is not None → 409 "Loan already returned"
    - Set loan.returned_at = datetime.now(timezone.utc)
    - Load Copy by loan.copy_id; set copy.status = CopyStatus.available
    - await session.commit(); await session.refresh(loan)
    - Eager-load relationships for response
    - Return LoanResponse.model_validate(loan)

    GET /api/librarian/loans (query params: overdue: bool = False, page: int = 1, page_size: int = 20 → LoansListResponse):
    - Overdue is always computed at query time — due_date < now() AND returned_at IS NULL (per D-01). There is NO stored status column for overdue, NO background job, NO APScheduler dependency in Phase 3.
    - Base query: select(Loan) where returned_at IS NULL, eager-load copy→book and borrower via selectinload
    - If overdue=True: also filter where due_date < datetime.now(timezone.utc)
    - Count total with a separate count query
    - Apply offset/limit pagination
    - Return LoansListResponse(items=[LoanResponse.model_validate(l) for l in loans], total=total)

    **student_loans_router** (prefix="/loans", dependencies=[Depends(get_current_user)]):

    GET /api/loans/my (current_user from get_current_user injected as parameter → LoansListResponse):
    - Query Loan where user_id = current_user.id AND returned_at IS NULL
    - Eager-load copy→book for response
    - Return LoansListResponse(items=[LoanResponse.model_validate(l) for l in loans], total=len(loans))

    - from app.routers import loans
    - app.include_router(loans.loans_router, prefix="/api")
    - app.include_router(loans.student_loans_router, prefix="/api")

    Add these two include_router calls after the existing books router includes.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→POST /api/librarian/loans/checkout | Untrusted copy_id and user_id from librarian client; must validate both exist and roles match |
| client→PATCH /api/librarian/loans/{loan_id}/return | Untrusted loan_id; must validate ownership and current state |
| client→GET /api/loans/my | Authenticated student; user_id must come from JWT sub claim, not from request body |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | GET /api/loans/my | mitigate | user_id sourced from get_current_user dependency (JWT sub), never from query param or body |
| T-03-02 | Tampering | PATCH /api/librarian/loans/{id}/return | mitigate | returned_at idempotency check — 409 if already returned; copy status mutation only via server |
| T-03-03 | Elevation of privilege | POST /api/librarian/loans/checkout | mitigate | user.role == UserRole.student enforced before checkout; require_librarian on loans_router prevents student access |
| T-03-04 | Denial of service | checkout loop | accept | no rate limiting in v1; library context — low-volume, authenticated users only |
| T-03-05 | Tampering | npm/pip/cargo installs | mitigate | no new packages in this plan — SQLAlchemy, FastAPI, Pydantic already in requirements.txt |
| T-03-SC | Tampering | pip installs | mitigate | no new dependencies; existing requirements.txt packages are pinned |
</threat_model>
