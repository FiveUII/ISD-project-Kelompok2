# Plan 02: Backend Catalog API — Books, Copies, ISBN Fetch

**Phase:** 2 — Catalog
**Wave:** 1 — Backend API (blocked on Wave 0 for migration; frontend Plan 03 runs in parallel after this)
**Depends on:** 02-01 (Alembic 0003 must be applied before API starts)
**Requirements satisfied:** CATL-01, CATL-02, CATL-03, CATL-04, CATL-05, CATL-06, CATS-01, CATS-02
**Mode:** mvp

## Goal

All backend catalog endpoints are implemented — librarians can CRUD books and manage copies, students can search the catalog, and the ISBN auto-fetch service calls the full Open Library 3-step chain with correct error handling.

## Threat Model

- **SSRF via ISBN input (T-02-01):** The ISBN value is interpolated into an external URL. Validate server-side: only `[a-zA-Z0-9-]` allowed (10-13 chars). Reject before any HTTPX call. Applied in `isbn_service.py` before constructing the Open Library URL.
- **RBAC bypass (T-02-02):** Librarian endpoints (POST/PUT/DELETE books, POST copies, PATCH copy lost) MUST use `router = APIRouter(dependencies=[Depends(require_librarian)])` — NOT inline per-route checks. The GET /books endpoint uses a separate router with only `Depends(get_current_user)`.
- **Soft-delete filter bypass (T-02-03):** Every SELECT on `books` and `copies` MUST include `Book.deleted_at.is_(None)` and `Copy.deleted_at.is_(None)`. No query may omit this filter.
- **N+1 availability (T-02-04):** Available count MUST be computed via correlated subquery in the same SELECT — never via Python loop. Pattern from research must be followed exactly (D-12).

## Context

This plan builds the complete backend API. The single `GET /api/books` endpoint serves BOTH students (via `/catalog`) and librarians (via `/librarian/books`). The response includes `available_count` and `total_count` (librarians use total_count; students display only available_count per D-11, enforced on the frontend).

**Router design (per note 6 in task prompt):** Use a SINGLE `/api/books` prefix with split permission levels per endpoint:
- A `student_router = APIRouter(prefix="/books", dependencies=[Depends(get_current_user)])` for GET /books and GET /books/{id}
- A `librarian_router = APIRouter(prefix="/books", dependencies=[Depends(require_librarian)])` for POST/PUT/DELETE /books and copy management
- Both registered in `main.py` under `/api` prefix

This avoids duplicating the `/api/books` path while keeping RBAC enforced at the router level (PITFALLS C4).

The ISBN fetch endpoint `POST /api/books/isbn-fetch` is on the `librarian_router` (only librarians add books). It is registered BEFORE `GET /api/books/{id}` to prevent FastAPI routing the literal path `/isbn-fetch` as a book ID.

### Task 2: ISBN Fetch Service

**Why:** The Open Library fetch logic is complex (3 sequential HTTP calls, polymorphic description, RISK-01 and RISK-02). Isolating it in a service function keeps the router clean and the logic testable.

**Files:**
- `backend/app/services/isbn_service.py`

**Steps:**
- [ ] Create `backend/app/services/isbn_service.py`

**Validation function:**
```
def _validate_isbn(isbn: str) -> bool:
    import re
    return bool(re.match(r'^[a-zA-Z0-9-]{8,17}$', isbn))
```

**Description normalizer (RISK-01 — MUST handle all three shapes):**
```
def _extract_description(raw) -> str | None:
    if raw is None: return None
    if isinstance(raw, str): return raw or None
    if isinstance(raw, dict): return raw.get("value") or None
    return None
```

**Cover URL builder:**
```
def _build_cover_url(covers: list | None) -> str | None:
    if not covers: return None
    cover_id = covers[0]
    return f"https://covers.openlibrary.org/b/id/{cover_id}-M.jpg"
```

**Main service function `fetch_book_by_isbn(isbn: str) -> ISBNFetchResponse`:**
- [ ] Validate ISBN with `_validate_isbn(isbn)`. If invalid, raise `HTTPException(400, "Invalid ISBN format")`
- [ ] Define a module-level constant: `OL_USER_AGENT = "LibraryManagementSystem (faviannazmi@gmail.com)"` — include this header on ALL three HTTPX calls to get 3 req/sec rate limit instead of 1 req/sec.
- [ ] Use `async with httpx.AsyncClient(timeout=5.0) as client:` for all calls. Pass `headers={"User-Agent": OL_USER_AGENT}` on every `client.get()` call.
- [ ] **Step 1 — Edition call:** `GET https://openlibrary.org/isbn/{isbn}.json`
  - If response status is 404: return `ISBNFetchResponse(found=False, error="not_found")`
  - If any other error / exception: return `ISBNFetchResponse(found=False, error="unavailable")`
- [ ] **Step 2 — Author call (RISK-02):** Edition response has `authors: [{"key": "/authors/OL..."}]`. Extract the first author key. If present, fetch `GET https://openlibrary.org/authors/{key}.json` and extract `name` field. If authors list is empty or call fails, `author_name = None`.
- [ ] **Step 3 — Works call (for description):** Edition response has `works: [{"key": "/works/OL..."}]`. Extract the first works key. If present, fetch `GET https://openlibrary.org/works/{key}.json` and extract `description` using `_extract_description()`. If works list is empty or call fails, `description = None`.
- [ ] Extract `title` from edition response directly (it is a plain string on the edition)
- [ ] Extract `covers` from edition response: `covers = edition_data.get("covers", [])`; build cover_url with `_build_cover_url(covers)`
- [ ] Return `ISBNFetchResponse(found=True, title=title, author=author_name, description=description, cover_url=cover_url)`
- [ ] Wrap the entire 3-step block in a broad `except Exception` that returns `ISBNFetchResponse(found=False, error="unavailable")` — network timeouts and JSON parse errors are treated as unavailable (D-02)
- [ ] Import `httpx`, `HTTPException` from `fastapi`, and `ISBNFetchResponse` from `app.schemas.catalog`

Use EXACTLY this pattern from the research:
```python
available_count_subq = (
    select(func.count(Copy.id))
    .where(and_(
        Copy.book_id == Book.id,
        Copy.status == CopyStatus.available,
        Copy.deleted_at.is_(None),
    ))
    .correlate(Book)
    .scalar_subquery()
)

total_count_subq = (
    select(func.count(Copy.id))
    .where(and_(Copy.book_id == Book.id, Copy.deleted_at.is_(None)))
    .correlate(Book)
    .scalar_subquery()
)
```
