## Phase Goal

**As a** library administrator, **I want to** have role-based access enforced at the API level, seed an admin superuser, promote accounts to librarian, and let any user reset a forgotten password, **so that** librarian capabilities are protected and accounts are recoverable.

<objective>
Complete the auth foundation: enforce RBAC via FastAPI dependency injection at the APIRouter level (NOT middleware, NOT per-route inline checks — PITFALLS C4), seed an idempotent admin superuser from env vars (D-03), expose the librarian-promotion endpoint (D-03, D-05 — API-only, no admin UI), and deliver the password-reset flow end-to-end (AUTH-03).

Purpose: Implements AUTH-03 (password reset) and AUTH-04 (API-level RBAC). The RBAC dependencies created here are reused by every protected endpoint in Phases 2–4.
Output: Working role enforcement (401/403/200), admin seed, promote endpoint, and forgot/reset-password flow.
</objective>
